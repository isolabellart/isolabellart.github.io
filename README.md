# Postilla website preview

This branch contains a first bilingual (English / Italian) landing page for Postilla.

- Design direction: the dark, device-led 2026 Wisp presentation, adapted to Postilla's charcoal, warm ivory and orange identity.
- App imagery: the five real screenshots and official brand panel are referenced directly from the public Postilla Android repository. No app screens have been invented.
- Interactions: language switch, responsive mobile navigation, scroll progress/reveal and swipeable screenshot gallery.
- This branch is not deployed. GitHub Pages links are public; an actually private online preview needs an authentication layer such as Cloudflare Access.

Source app: https://github.com/isolabellart/postilla-android
